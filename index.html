A movie catalog built like a backend project, not a mockup.

MovieShelf demonstrates relational modelling, PostgreSQL full-text and trigram search, authentication, production checks and end-to-end browser testing.

View UI preview Explore source code

This GitHub Pages site is a static preview. The full application is Django and requires a server runtime, so authentication and database search are intentionally not simulated here.

What is implemented

Production-oriented backend signals

The repository keeps the architecture deliberately close to Django while exercising the parts that matter in a real service.

Relational integrityDatabase-backed constraints for ratings, durations, genres and duplicate cast/director credits.
PostgreSQL searchSearchVector, websearch queries, ranking plus GIN and pg_trgm indexes, with SQLite fallback.
Deployment checksHealth endpoint, Gunicorn, WhiteNoise, strict environment parsing, CI and production security checks.
